# Release 1.2.2

This maintenance release refreshes the locked PHP and JavaScript dependencies,
including WordPress security patches, SymPress packages, PHPStan, PHPUnit, Sass,
PostCSS and the Playwright browser tooling. Immutable GitHub Actions references
are refreshed as well.

The deployment package version and the fixed scheduled update-canary source
advance to 1.2.2. The feature plugin retains its independent version.

The release requires passing PHP validation, dependency audits, static analysis,
unit tests, production asset builds and the real WordPress/Playwright workflows.
